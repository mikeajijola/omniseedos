# Contributing

Omniform owns semantics, OmniSeed owns execution, and this repository owns interaction. Contributions are welcome from founders, operators, UX/accessibility practitioners, AI and robotics engineers, and software developers.

Run `npm install && npm run dev` for a fixture-backed environment, then `npm run lint && npm test && npm run build`. Keep actions keyboard and screen-reader accessible and back them with structured OmniSeed operations. Do not infer capability status in the UI. Open a focused pull request describing the capability/outcome, actors considered, and evidence.
