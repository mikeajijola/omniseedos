# Generated operation projections

OmniSeed OS asks the transport for the current capability registry. `OperationAction`, `OperationForm`, `OperationApproval`, `OperationResult`, and `OperationUnavailable` compose that metadata into accessible affordances; they do not generate business logic.

Lily receives the same agent-eligible operations and cannot propose an absent executable capability. The public demo reads the checked Omniform materialization and truthfully marks governed mutation unavailable. Live mode receives implementation and policy availability from OmniSeed.

```text
Omniform → OmniSeed registry → OS / Lily / CLI / API / machine
                              ↓
                      governed execution
                              ↓
                    evidence and reconciliation
```
