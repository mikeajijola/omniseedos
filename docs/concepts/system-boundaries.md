# System boundaries

```text
Omniform definition → OmniSeed Core → OmniSeed runtime transport → OmniSeed OS
```

OmniSeed OS is an interface to shared capabilities. Omniform owns portable organisational meaning; OmniSeed owns execution and state; `OmniSeedTransport` is the capability-access boundary; OmniSeed OS is the human/agent operating interface. UI routes render transport outputs. Eve reads through the same transport. Physical actors use the same structured operations without changing business capability semantics.
