# Run against live OmniSeed

Clone the repositories beside one another. In OmniSeed:

```sh
npm install
npm test
npm run runtime
```

In OmniSeed OS:

```sh
npm install
npm run test:live
npm run dev
```

Open `http://localhost:3000`. The default `LiveTransport` calls OmniSeed at `http://localhost:8787`; override it with `OMNISEED_URL`. Initially Customer Research is Realised and Customer Support is Missing. Generate the support-agent plan, review its reason/approval/reversibility, then approve all development-safe changes. OmniSeed applies through the local provider, emits events, and recalculates Support as Realised. The OS reloads that runtime state—it does not infer it.

Use `npm run dev:fixtures` when developing without the runtime.
