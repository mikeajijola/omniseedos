# Fixture-driven development

Run `npm install`, `npm test`, and `npm run dev`. The local page uses `fixtures/startup.json`; no runtime, cloud account, credentials, Docker, or database is required. Six fixtures cover an empty company, startup with a gap, partial company, degraded company, enterprise re-founding, and semantic findings. Treat fixture state as OmniSeed output; components must not recalculate it.
